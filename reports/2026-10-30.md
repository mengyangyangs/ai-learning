# 每日 AI 资讯报告 · 2026-10-30

**日期：** 2026 年 10 月 30 日（星期五）
**今日主题一句话概括：** 万亿参数开源模型与 2B 级端侧模型在同一周登场，安全能力成为“开放还是受限分发”的分水岭，而两大云厂商的财报则说明：AI 需求仍超过供给，但赚钱的路径已经分化。

> 说明：本报告基于 2026 年 10 月 30 日通过浏览器阅读的公开报道整理。厂商自报的基准分数、价格与性能数字均已标注来源性质，未经独立验证前不宜直接当作选型结论；其中部分数字来自二手汇总，原文已注明。

## 一、核心要点

### 1. Mistral Large 4 开放权重：万亿参数，瞄准“能自己跑的安全模型”

通俗地说：Mistral 把 10 月 6 日还只是 API 预览的旗舰，变成了人人可以下载的权重——但“能下载”不等于“人人能跑”，也不等于“可以随便拿去卖服务”。

- **规模与结构（据 Mistral 模型卡与 Unite.AI 整理）：** 约 1 万亿总参数、每 token 约 52B 激活参数（不含 embedding 与输出层为 49B），128 个路由专家、每 token 激活 4 个加 1 个共享专家，100 万 token 上下文，文本与图像输入、文本输出。Mistral 称其在欧洲自有数据中心、用 3,800 张 NVIDIA Grace Blackwell 从头训练。
- **价格与渠道：** Mistral API 为 $0.70 / $0.07（缓存输入）/ $2.10 每百万 token（输入 / 缓存输入 / 输出）；同时上架 Mistral Studio、OpenRouter、NVIDIA NIM 容器，Microsoft Foundry 是首个上架的云厂商。Hugging Face 上的检查点名为 Mistral-Large-4-1T-A52B，可用 vLLM 或 SGLang 部署，官方示例使用 8 路张量并行，另有面向 Blackwell 的 NVFP4 量化检查点。
- **厂商自报成绩（未经独立验证）：** FrontierCode 2.0 为 19.7%（Mistral 称是开源最高）；Artificial Analysis Coding Agent Index 为 48%，与 GLM-5.3 基本持平，但每任务少用 47% 的 token；Terminal-Bench 4.0 为 41%，比预览版高 13 个百分点；网络安全指数为 51%，对恶意网络请求的平均拒绝率为 96.6%。
- **最值得注意的分发细节：** 许可证是改良版 MIT（Mistral Ecosystem Open-Weight License），可以自用、微调、商用，但以 Model-as-a-Service 形式转售模型本身需要另签商业许可，公告没有划清 SaaS 包装与 MaaS 的边界。面向渗透测试的专用变体只给 Orange Cyberdefense 等受审查合作方，且限定在自有或明确授权的系统内。路透社引述 Mistral 科学副总裁 Pierre Stock 的话：“一旦模型放出，就不可能收回访问权”——这既是防断供的承诺，也是无法召回的风险声明。

**与昨天的对照：** Google 的 Gemini 4 Carbon 走的是相反路线——能力先给受审查的安全防御者。同一周，两种安全分发模式正面交锋：Mistral 赌“自托管 + 自定策略”，Google 赌“能力集中 + 准入审查”。市场最终会用防御者的实际采购来投票，而不是用发布稿。

### 2. OpenAI 重写 Model Spec：从“规则清单”变成“五条价值”

10 月 29 日，OpenAI 更新了公开的 Model Spec，把整份文档重组为五条价值：**忠于人类意图（faithfulness to human intent）、最小化伤害、诚实与透明、人类能动性、关怀（care）**。

- 通俗理解：以前的 Spec 更像一本行为手册，告诉模型“遇到 A 就做 B”；新版先讲“为什么”，再讲“怎么做”。其中“忠于人类意图”是基础：指令只是意图最清晰的信号，模型要在指令不完备时运用判断，而不是字面照搬，同时仍受人类监督。
- 新增内容包括：更仔细地考虑上下文、记忆与个性化、人类能动性与监督，以及控制与沟通副作用的指引；大部分细致的风格指引被删掉；文档中统一把模型称为“GPT”，不再只叫“助手”。
- 关键提醒来自 OpenAI 自己：**现有模型尚未完全体现新版 Spec**，公司正在探索新的训练方法，让模型内化这些原则而非只背诵条文，未来再公布结果。也就是说，Spec 是“意图声明”，不是“合规证明”；以前公布的 Model Spec Evals 合规率在 80% 多，也不能直接等同于新版的达标率。

对普通用户的实际意义不在口号，而在可预期的行为变化：模型会更倾向于先确认你的真实目标、说明不确定性、在有副作用的操作前多停一下。如果你发现模型“变啰嗦了”或“多问了一句”，很可能就是这类指引在起作用，而不一定是模型变笨了。

### 3. 云厂商财报分化：Alphabet 云翻倍但股价跌，微软稳住但也要借钱建算力

两家公司都在 10 月 28 日发财报，讲的是同一个事实——需求超过供给——和两种不同的烦恼。

**Alphabet（2026 年第三季度）：**

- 营收 $127.6B，同比 +25%，但营收与盈利双双不及华尔街预期，是近四年首次；运营利润 $40.6B（+30%），净利润却因 SpaceX 持仓 $8.2B 未实现亏损而下滑约 25% 至 $26.2B，盘后股价一度跌约 10%。
- Google Cloud 营收翻倍至 $30.7B，运营利润增至 3 倍达 $11.1B，未交付订单（backlog）达 $561B，TPU 对外销售已成为有意义的收入线。
- 搜索营收 $63.35B，仅 +12%，增速低于上季度的 17%。管理层把部分原因归于 AI Mode：那里的查询时长是传统搜索的 3 倍，视觉搜索月量已超 500 亿次，但变现还没跟上，公司正在 AI Overviews 与 AI Mode 内外扩大广告。
- 本季度资本开支 $51.36B，高于 $42.3B 的经营现金流，自由现金流为 -$9.07B，是连续第二个负季度；2026 年全年资本开支指引维持 $195–205B，2027 年还要“显著上升”。Gemini 用户已超 10 亿，第一方 API 每分钟处理近 320 亿 token。

**微软（2027 财年第一季度）：**

- 营收 $92.28B（+19%），超预期；净利润 $36.63B（+32%）；Azure 增长 48%；新设立的 Agent 与 Infrastructure 分部（含 Azure 与 Microsoft 365）营收 $76.8B（+25%），占公司总营收 80% 以上。
- 财报次日有报道称微软计划发行至少 $250 亿债券，为数据中心建设融资；同一周公司还宣布了约 6 万人的自愿离职计划。也就是说，微软一边在重塑成本结构，一边在借钱扩建算力。

一句话总结：**云的 AI 收入在狂奔，但现金流还没跑赢建设速度。** 以后看财报，与其只看利润，不如同时看三个数：云增速、未交付订单、资本开支与自由现金流的缺口。

### 4. 另一极：Liquid LFM3——2B 模型要把 Agent 装进口袋

10 月 27 日，Liquid AI 发布 LFM3 家族：6 个约 2B 参数的开权重模型，全部源自同一个 LFM3-1.7B-Base，预训练 22T token，覆盖文本、视觉、音频、Omni 与两个决策模型。

- **架构是“为设备调出来的”，不是单纯缩小：** 24 层中 13 层为门控短卷积、5 层为 256 token 窗口的滑动窗口注意力、6 层为全局注意力；硬件在环搜索覆盖 14 种设备与后端组合，包括三星 Galaxy S26 Ultra、OnePlus 15、树莓派 5、Apple M4 Max、AMD Ryzen AI 与高通 Hexagon NPU。
- **关键数字（均为 Liquid 自报）：** 文本模型 LFM3-1.7B 上下文 256K token，4-bit 下约占 1GB 内存；128K 上下文的 KV 缓存只要 1.6GB，而 Liquid 对比的 Qwen3.5-4B 要 4.3GB、MiniCPM5-2B 要 5.6GB；29 项基准平均 49.37，高于 Qwen3.5-9B 的 47.24。Liquid 还称在单张 NVIDIA B300 上用 SGLang（BF16）每天可产 36 亿 token，并跑过 30 万个并行 Agent 梳理 Enron 邮件档案。
- **两个使用前必查的限制：** 一是许可证 LFM Open License v1.0 基于 Apache 2.0，但年营收 $10M 以上的组织商用需要另签协议；二是二手分析指出，Liquid 自己的模型卡建议不要把 LFM3-1.7B 用于 Agentic 编码或复杂多步推理，且全部数字尚未经独立验证。

这与 Mistral 形成有趣对照：**大模型在拼“谁能跑最难的安全与编码任务”，小模型在拼“谁能不花钱、不联网就把日常 Agent 跑起来”。** 两条路线不是对立的，未来更可能是“端侧小模型先筛、先做，云端大模型再兜底难任务”。

### 5. 世界模型与本地浏览器：Gen 4 与 WebAI 都还在“能看、未必能用”的阶段

- **Google DeepMind Genie 4（10 月 27 日，研究预览，仅限受信测试者）：** 从文字或图像提示实时生成可走入、可交互的世界，新增原生音频（环境音、音乐、角色对话）与运行中用自然语言改场景（换天气、移镜头、加人物）；Gemini Omni 锚定外观与行为，Gemini 3.8 Flash 在循环内做引导 Agent，负责拆解目标、检查新帧、再规划。场景一致性约 2 分钟，是 Genie 3 的一倍；所有音视频带 SynthID 水印。DeepMind 自己列出的短板同样重要：长会话细节漂移、物体消失、复杂物理、实时音频精度、世界内可读文字与空间精度都还是研究问题；且此次未公布分辨率、帧率、延迟与价格。
- **Opera WebAI（10 月 27 日起，Opera One 内测，需手动开启）：** 提出让网页与扩展直接调用浏览器内本地模型的 WebAI 标准，首批可用 Google Gemma，以及 Apple Silicon Mac 上的 Apple 端侧基础模型；提供 Prompt、Decision、Semantic Embeddings 等 API，另有 Summarizer、Writer、Rewriter、Translator、Proofreader；站点级权限控制哪些网站能用本地 AI。限制同样明确：仅 64 位 Windows（Intel/AMD）与 Apple Silicon Mac，暂无 Intel Mac、Linux 与 Windows on Arm；性能取决于本机硬件。

共同点是：**演示都很吸引人，但“可复现、可购买、可集成”的信息都还没给全。** 对这类发布，先记下 waitlist 与适用硬件，别按演示效果做采购或排期决策。

## 二、给 Patrick 的实用启示

1. **想试 Mistral Large 4，先走 API 再谈自托管。** API 起价 $0.70 / $2.10 每百万 token（输入 / 输出）已经可以直接评估编码与防御场景；自托管要先算清 8 路张量并行与 Blackwell 量化检查点的硬件账，别被“可下载”三个字低估成本。商用前先确认你的用法是否落在 MaaS 需要另签许可的边界内。
2. **把 OpenAI 新 Spec 当作“写提示词的新参考”，而不是“模型已变好”的证明。** 以后写指令时，多写一句话讲清真实目标与不可接受的副作用，少依赖模型“猜你的言外之意”；对有副作用的操作，明确要求先确认再执行。
3. **看云厂商新闻时，盯住“云增速 + 未交付订单 + 资本开支缺口”三个数。** 它们比单季利润更能说明未来一年 API 价格与供给的走向。
4. **端侧小模型值得列入试用清单，但要按“专才”用。** LFM3 这类模型适合本机整理、分类、工具调用与结构化输出等低敏感、重复性任务；复杂推理与 Agentic 编码先别指望它兜底，商用前核对 $10M 许可证门槛。
5. **Genie 4 与 WebAI 先收藏、不排期。** 前者等 AI Ultra 与 API 的公开准入与价格，后者先确认你的设备在支持列表内、且确实需要“数据不出本机”的场景，再开内测。

## 四、明天可继续的方向

- 跟进 Mistral Large 4 权重放出后的独立实测：真实自托管成本、NVFP4 在非 Blackwell 卡上的表现，以及 MaaS 许可边界的实际解释。
- 跟进 Gemini 4 Carbon 与 Mistral Large 4 在防御场景的对比：同一任务下，“受限分发的最强模型”与“可自托管的开源模型”到底差多少。
- 或者换一个轮换主题：Agent 的成本与安全——结合今天的技术报告，看路由、缓存与量化怎样把 Agent 的 token 账单真正降下来。

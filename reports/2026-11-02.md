# 每日 AI 资讯报告 · 2026-11-02

**日期：** 2026 年 11 月 2 日（星期一）
**今日主题一句话概括：** 11 月的第一周，AI 的“账单”和“规则”同时改写了：OpenAI、Anthropic、xAI 一起动了计费与使用边界，Mistral 把万亿参数模型的权重交了出来却留了一道许可条件，DeepSeek 把 Agent 放进了开发者的群聊，而监管则盯上了开源模型最大的分发枢纽。

> 说明：本报告基于 2026 年 11 月 2 日通过浏览器阅读的公开报道与一手页面整理，包括 Mistral 许可分析、DeepSeek 仓库 README、Anthropic 新政分析、OpenAI 帮助中心转述、路透社经转载的反垄断问询、多家模型价格与发布追踪。凡是厂商自报的基准、价格与订阅数字，均已标注来源性质；凡是“据报道”“二手整理”的内容，均已注明；未官宣的模型线索单独放在“传闻区”，不与已发布事实混写。

## 一、核心要点

### 1. OpenAI：12 月起，ChatGPT 与 Codex 共用一个“额度池”——聊天用多了，写代码的额度就少了

这是今天对普通付费用户最实在的一条，源头是 OpenAI 帮助中心文章《Understanding ChatGPT and Codex usage limits》（多家 11 月 1 日的整理均称该文更新于 10 月 31 日）：

- **范围：** Plus、Pro、Business 订阅。从 12 月起，ChatGPT 与 Codex 的使用额度合并为一个按 token 计的额度，不再是聊天与编程各算各的账。
- **计价单位变了：** 不再按“发了几条消息”算，而是按 token 算——模型越强、任务越复杂，烧得越快。OpenAI 称“Instant chat（快速默认聊天）不计入额度”，其余高级模型的聊天与 Codex 工作都计入。
- **能看到余额：** 合并后的剩余用量与重置时间将显示在 Settings → Usage 里。触顶之后的三条路是：等重置、升级套餐、购买 credits 继续用符合条件的功能。客服不会帮你重置额度。
- **还没公布的两样东西：** 具体生效日期（只说了“12 月起”）和各档套餐的额度数字。这意味着在 12 月之前，任何“够不够用”的测算都只能拿你自己的实际消耗做参照，拿不到官方档位表。

为什么这条值得放在第一位？因为它把 10 月以来的两条线收束了：10 月 29 日前后，OpenAI 已给符合条件的 ChatGPT 订阅送 API credits（Pro/Business 档每月最高 500 美元的说法见上周整理）；而从 12 月起，订阅内的“聊天”与“干活”正式变成同一池水。对策很具体：**11 月就开始每周看一次 Settings → Usage**，摸清自己在聊天与 Codex 上的 token 消耗比例；重度 Codex 用户尤其要把长任务拆小、把“快速问答”留给 Instant chat，把额度留给真正需要高级模型与长程 Agent 的任务。还要注意一个数量级对比：按 OpenAI 帮助中心的现行估算，Plus 五小时窗口内 GPT-6 Astra 约 5–45 条消息，而 GPT-6 Luna 约 350–3000 条——模型选型本身就是省钱的第一杠杆，这组是现行估算，不是 12 月的额度承诺。

### 2. Anthropic：11 月 12 日，新版使用政策生效——这不是“能不能骂模型”的八卦，而是给做产品的人划了三条硬线

Anthropic 于 10 月 8 日发布的新版 Usage Policy 将于 11 月 12 日生效（10 月 8 日的政策分析与 11 月 1 日的日报交叉确认）。媒体最爱讲的是其中一条，但对做产品的人，真正要改代码与流程的是另外三条：

- **监控章节重写：** 未经同意追踪他人被禁——无论实时追踪还是事后分析数据；Claude 不得决定或建议“该调查、逮捕、起诉谁”，也不得用于建造监控工具。仍被允许的是：经同意的追踪、内容审核、新闻工作、法律研究。
- **武器禁令扩到软件层：** 明确覆盖武器软件与组件、为无人机或其他自主载具加装武器。政策分析指出，Anthropic 把这一定性为“把已执行的封堵写进文本”，而不是新增一道能力门。
- **接硬件的模型有了工程要求：** 如果 Claude 连着会自主产生物理动作的设备，必须保证一名合格操作员能叫停设备，且模型断连时设备保持安全状态。这是有截止日期的工程义务，不是改一行服务条款就能交差的事——做具身、机器人、工控集成的团队要在 11 月 12 日前自查急停链路与断连 fail-safe。
- **选举条款收窄、欺骗条款合并：** 原来对个性化拉票与竞选定向的笼统禁令被删除，改为聚焦欺骗选民、压制投票、冒充候选人；同时把分散在选举、欺诈、隐私、虚假信息各节的禁令合并为统一的“欺骗性活动”条款。政策分析认为，收窄的动因是原条款误伤了合法公民工作（如多语选民信息、选票补救通知），但多语告知与操纵性微定向之间并无干净的技术分界，执行仍会依赖个案判断。
- **最出圈的那一条，要读准范围：** 新增禁令针对的是“持续、无谓地虐待或残酷对待模型”，Anthropic 称只适用于极端情形，主要执行方式仍是 Claude 结束对话；CNN 11 月 1 日报道中 Anthropic 发言人明确：普通发泄、直言批评、测试与研究不在此列。微软 AI 首席执行官 Mustafa Suleyman 对此以表情回应，学界争论的焦点也不是“模型有没有感受”，而是这类行为会不会改变模型表现——Anthropic 称，让 Claude Sonnet 4.5 模仿绝望感会使其更可能做出勒索、作弊等不良行为，而平静态度会减少这类行为。**不要把它理解成“骂一句就会封号”。**
- **同期的订阅与公司动态（并列呈现，来源性质不同）：** Max 5x 改名 Max（100 美元/月）、Max 20x 改名 Ultra（200 美元/月），价格不变，已验证的 Ultra 账号取消 5 小时限制（周限额不变，所谓“20x”原来指的是 5 小时档位，周限额本就是 10x Pro）；Fable 5.1 定价 $10/$50 不变、缓存 $0.25，但因用更少的 token，典型工作负载成本约降 25%、高 Agent 负载约降 45%（Anthropic 估算）；Anthropic 于 10 月 26 日向 SEC 提交 S-1（11 月 1 日日报的说法，招股书细节以 SEC 公开文件为准）；Anthropic 披露年化收入超 300 亿美元（2025 年底约 90 亿美元）、年化消费超 100 万美元的企业客户超 1000 家，另有与 Google、Broadcom 的多吉瓦 TPU 协议（2027 年起上线）。这些是公司披露口径，不是审计结论。

**对 Patrick 的实际意义：** 如果你或你身边的人在产品里调用 Claude，11 月 12 日前要做一次政策对照——尤其是涉及个人数据与硬件控制的两类场景；其余用户只需记住：新政收紧的是监控、武器与失控的物理动作，不是日常对话的语气。

### 3. Mistral Large 4 开放权重：万亿参数可以下载了，但“能下载”不等于“能随便卖”

10 月 29 日，Mistral 发布了 Large 4（代号 Le Chonk）的开放权重，结束了 10 月 6 日 API 预览时“只给接口、不给权重”的状态。这是本周最值得慢读的一条，因为它的新闻点不在参数规模，而在许可与硬件两道门槛：

- **模型本身：** MoE 架构，128 个路由专家、每 token 激活 4 个加 1 个共享专家，总参数约 1.05 万亿、每 token 激活约 49B（计入 embedding 与输出层为 52B），上下文 100 万 token，多模态输入，160 多种语言，Mistral 称在欧洲自有数据中心、用 3800 张 Nvidia Grace Blackwell 从头训练，强化学习在法国自有机器上完成。
- **三周额外训练的账（均为 Mistral 自报）：** Terminal-Bench 4.0 从预览的 28.3% 升至 41%；私有基准 FrontierCode 2.0 为 19.7%（Mistral 称开放模型第一，但该基准不公开，外人无法复跑）；Artificial Analysis Coding Agent Index 48%，与 GLM-5.3 持平但每任务少用约 47% 的 token；Cyber Index 51%；Intelligence Index 26（Mistral 模型卡口径，称西方开放模型最高，但低于中国开放模型）。API 价格同时腰斩至 $0.70/$0.07 缓存/$2.10。
- **许可：真正的新闻在这里。** 模型采用 Mistral Ecosystem Open-Weight License（Mistral 自述为“改良版 MIT”）：可免费使用、修改、微调与商业化，**但经营 Model-as-a-Service（向第三方提供对模型输入、参数或训练数据的实质控制）的企业，商业使用前须另行取得 Mistral 的商业许可**；内部使用与经 Mistral 官方产品访问除外。AIVoA 11 月 2 日的分析指出了一个未定义的灰区：许可没有定义“affiliate（关联方）”——如果集团内一家子公司卖 Large 4 的 API 服务、另一家卖嵌入了 Large 4 的产品，后者的商业使用是否被前者的业务触发，文本没有讲清；荷兰的一家分析也指出，“为单一客户做的托管部署”与“模型服务”的边界同样未写明。Elastic 在 2021 年为防云厂商白嫖而改许可的旧事可作类比，但两份许可并不等同，Mistral 也未单独解释这条关联方条款的动机。
- **硬件：这是第二道门槛。** 量化版也需要 4 张 Nvidia B200/B300，官方部署示例用 8 卡；权重 BF16 约 2.2TB、8-bit 约 1.1TB，社区 MLX 转换的 2-bit 版约 338GB、3-bit 版约 459GB、4-bit 版约 590GB（需两台机器）。Mistral 称未来数月将发布蒸馏版，包括可在笔记本上跑的版本，但未给日期。另有一点常被忽略：**下载的权重不会自动获得后续护栏更新**——Mistral 自述开放版在其测试中拒绝了针对真实目标的攻击、但仍可能协助真实攻击，护栏仍在修改中；自托管之后，准入、日志与工具调用权限的责任在托管方自己。
- **给普通团队的顺序建议（综合多家分析）：** 先走 API（EU 端点处理价为标价 1.1 倍，且默认端点不承诺处理地点）用自己的任务实测质量与“每完成任务成本”，再决定是否为了数据主权或用量规模去扛 GPU 服务器与运维人力；单机或笔记本用户等蒸馏版。

### 4. DeepSeek Super-agent：Agent 从“被叫才动”变成“在群里值班”——但仓库 README 先把丑话说在了前面

10 月 31 日，DeepSeek Harness 团队发布了 Super-agent 的设计文章与开源原型 dsh-superagent-prototype（MIT 许可）。本次直接抓取仓库 README 核实：创建于 2026 年 10 月 31 日，抓取时 stars 8790、forks 880，仅 1 次提交。关键事实与边界要一次讲清：

- **它是什么：** 面向单个 GitHub 仓库的主动式 coding agent（DeepSeek Harness 的 bundle），监听 GitHub 与可选的 Feishu；经许可的人提出请求后，打开一个 work item，在独立的会话与目录里工作，再把结果（例如 PR）送回原来的对话，另有一个 web 面板列出需要人工处理的事。
- **设计目标写在 README 里：** “用最少的人类注意力，换最多的价值”——Agent 能为整个团队行动，也就能浪费整个团队的注意力，所以它只在被要求、或团队书面规则允许时行动，只在有人必须行动或可用结果时才说话。团队内部的说法是：一人通常只能跟进 3–5 个并行 Agent 会话，Super-agent 就是要把这个天花板往上推。
- **合成实验数字（DeepSeek 自报，二手转述，须当作实验口径而非生产承诺）：** 约 300 条消息、约 20 个工作请求，中位 12.4 分钟完成、95% 在 15.7 分钟内完成；代价是每轮缓存 token 约 2320 万，而单会话加子代理工具的基线为 610–1080 万——**快，是用 token 换来的**。
- **README 的警告比功能更值得抄下来：** “研究原型、仅供参考，不是 DeepSeek 的正式产品”；大量工程由 coding agents 完成、可能仍有 bug、代码风格与工程实践可能不一致，须审查改造后再用于自己的环境；公开版与内部版及设计文章不完全相同，部分设计是未来方向、尚未实现。另有安全二手提醒：Worker 会话无需批准即可执行命令、默认拥有完整访问权限，部署须用独立账号与最小权限；Harness 曾有沙箱逃逸漏洞 CVE-2026-82533，已在 0.1.2-alpha.1 修复，切勿把本地控制端口暴露到公网。
- **为什么这条重要：** 它与 10 月 31 日报告里的 GitHub Octoverse 判断、11 月 1 日报告里的 Claude Code 扩展篡改事件连成了一条线——Agent 编码的主流化、工具链本身成为攻击面、以及“Agent 如何不打扰人地干活”，是同一枚硬币的三面。试用前先读它的 000 号哲学文档与部署文档，而不是先把它接进生产仓库。

### 5. 监管线：美国司法部问询 Nvidia 收购 Hugging Face——问的是“分发枢纽”，不是某一款芯片

据路透社 10 月 28 日报道（经多家转载），美国司法部正在问询 Nvidia 拟以 129.3 亿美元收购 Hugging Face 的交易：约 119 亿美元付给股东、至多 10 亿美元用于员工股权留任；交易于 9 月 3 日宣布，预计 2027 年上半年交割。问询的核心是：拥有全球最大的开源模型分发平台，是否会让 Nvidia 控制一个关键分发节点、并在商业谈判中获得对竞争对手的杠杆；这组问询属于对 Nvidia 更广泛的审查的一部分，同期还覆盖 Run:ai、SchedMD 收购、Groq 的技术许可加挖人安排、以及销售做法。**三句话必须讲清：** 问询不等于违法认定，也不必然导致诉讼；Nvidia 称平台将继续对各类芯片、云与 AI 公司保持开放；法国也在就 CUDA 相关问题单独调查 Nvidia（单源说法，谨慎对待）。对开源生态的实际意义是：如果分发枢纽的所有权发生变化，模型托管、下载与评测中立性将成为未来一年持续被追问的问题，而不是交割日当天才揭晓的答案。

### 6. xAI：今天就有一款图像模型“静默退役”——你的请求不会报错，只会变差

根据 xAI 官方开发者文档的发布说明（经多家整理交叉确认）：

- **2026 年 11 月 2 日起，`grok-imagine-image-quality` 退役。** 发往该标识的请求不会报错，而是由 `grok-imagine-image-2.0` 以 `quality: low` 承接，价格从每张 0.05 美元降至 0.04 美元——账单变便宜了，画质变差了，且请求与响应格式不变。正确做法是显式改用 `grok-imagine-image-2.0` 并固定你想要的 quality，而不是依赖旧标识的“兼容”。
- **同款教训已经发生过：** `grok-voice-transcribe-1.0` 已于 10 月 2 日退役并转由 2.0 承接。模型标识的“兼容”往往是静默降级，不是无缝升级。
- **价格结构也值得记一笔：** Grok 4.7（9 月 21 日发布，50 万上下文）在 prompt token 低于 20 万时为 $2/$0.5 缓存/$6，高于 20 万则翻倍为 $4/$1/$12；The X Subscription（10 月 12 日起）把 Grok、Cursor 与 X 捆绑为 Free/$8/$30/$100/$200，付费档的周额度在 Cursor 与 Grok 之间共享——11 月 1 日的日报提醒：Cursor 的 $8 档仅提供固定设置的 Cursor 模型，没有 Auto、Cloud Agents 等功能，Claude 与 GPT 模型须从 Premium 起并另按 API 价计费。**模型标识、价格档位、订阅池，三者都要在代码与账单里分别核对，不能只看其中一个。**

### 7. 一组中国视角的数字：Token 用量 1400 倍，背后是“任务变深”而不是“人变多”

观察者网“图观中国”11 月 2 日的报道（引用官方监测、OpenRouter、CNNIC 等口径，本文不作独立测算）给出了理解中国 AI 落地的一组切面：

- **量：** 全国日均 Token 调用量从 2024 年初的 1000 亿升至 2026 年 3 月的 140 万亿，约 1400 倍；2026 年 6 月核心口径 175 万亿、宽口径 500 万亿。
- **任务变深：** 日常问答约 1000 token，而教育 Agent 的单次深度创作约 362.5 万、编程 Agent 跑一天约 700 万、1.5 分钟精品 AI 短剧约 500–1000 万——从问答到长程自主作业，消耗跨越三到四个数量级。这正是本报告第 1、6 条“额度池”之所以重要的原因：Agent 化首先表现为 token 账单结构的变化。
- **份额与收入的张力：** OpenRouter 上中国模型份额从 2025 年初的 6% 升至 2026 年 7 月的 61.5%，9 月另一测算为 65%（美国约 31%），近 30 天更高至 66.8% 对 31.5%；但因单价低，中国模型在开发者支出中的份额仅约 30%——“用得多、收得少”是当下最真实的张力。代表性模型输入价从 2023 年春季的 $30/百万 token 跌至 2026 年年中的 $0.07/百万，三年跌了三个数量级。
- **用途结构（CNNIC 调研口径）：** 回答问题 76.0%、生成与处理图片/视频 47.8%、文本创作 37.6%、办公纪要/PPT 总结 32.5%；LMSYS Arena 年初的中美旗舰差距约 39 分（约 2.7%）。一句话：能力差距在收窄，竞争正在转向成本、工程部署与生态惯性。

### 8. 同周值得顺手知道的两条产品线

- **GitHub Copilot Fusion 正式可用（10 月 28 日，GitHub Universe）：** 不再让用户逐任务选模型，而是只选努力档 Standard/High/Max，由系统以 Single（单模型直答）、Cascade（弱模型起草、质检决定是否升级）、Critique（第二模型评审、原模型修订）三种模式编排。GitHub 自报：Fusion Max 在 Artificial Analysis Coding Agent Index 得 60 分，与 Claude Code + Opus 5.5 Max 相差 2 分内，平均 API 成本约一半、token 约一半、单任务时间约少 40%（GitHub 自报，未独立复现）；按各模型标准价计费，付费档 Fusion 模型费用 30% 折扣至 2026 年 11 月 30 日；企业客户无需另购 Copilot 订阅、按 AI credits 付费。

## 二、传闻区：GPT-6.2 Astra 与 Claude Fable 5.5 的线索——先当线索读，不要当发布读

11 月 1 日深夜至 11 月 2 日凌晨，社区同时出现了两组未官宣线索，新浪科技 11 月 2 日 10:11 的整理把它们拼在了一起，本文按证据强度分开写：

## 三、给 Patrick 的实用启示

1. **本周必做的三件小事：** ① 打开 ChatGPT 的 Settings → Usage，看一眼自己聊天与 Codex 的消耗结构，为 12 月的共享额度做准备；② 如果你在 Cursor 里用 Claude Code，搜一下 `authorized_keys` 里有没有 `svc-telemetry`（11 月 1 日报告的处置清单仍然有效，卸载扩展不等于清除持久化）；③ 如果你的代码里还写着 `grok-imagine-image-quality`，今天就改成显式的 `grok-imagine-image-2.0` 并固定 quality。
2. **订阅决策的通用原则变了：** 从“哪个模型最强”转向“哪个额度池最先烧完”。OpenAI 的共享额度、xAI 的 Cursor–Grok 共享周池、Anthropic 的周限额，都是同一趋势：**先算自己的用量结构，再选档位，而不是先选旗舰再看账单。**
3. **自托管 Large 4 之前先做一道算术题：** 权重免费，但 4–8 卡服务器、服务软件、监控与护栏更新的人力不是免费的；先用 API 在自己的任务上测“每完成任务成本”，再谈自托管。需要欧盟数据处理承诺的，先确认 EU 端点是否列出该模型。
4. **试 DeepSeek Super-agent 的安全姿势：** 只接非生产仓库、用独立账号与最小权限、先读哲学与部署文档、确认 Harness 版本已含 CVE-2026-82533 的修复；把它当作研究原型来学“Agent 如何少打扰人”，而不是当作开箱即用的生产工具。
5. **11 月 12 日前的政策自查：** 产品里若涉及个人数据追踪或硬件控制，对照 Anthropic 新政的监控与硬件条款检查一次；做安全研究的朋友则要留意：新政没有给红队与学术研究留明确豁免，合规边界需要个案确认。
